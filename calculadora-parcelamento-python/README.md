# Calculadora de Parcelamento

Projeto simples em Python que calcula o valor das parcelas com base na quantidade escolhida.

## Funcionalidades
- Cálculo de juros por quantidade de parcelas
- Exibição do valor da parcela
- Exibição do valor total

## Como executar

1. Abra o terminal
2. Navegue até a pasta do projeto
3. Execute: python main.py
